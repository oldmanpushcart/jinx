# 定时任务管理

定时任务系统按 Cron 表达式定时触发，触发时向 Agent 发送指定 prompt 执行。支持定时执行（指定具体时间点）和定期执行（周期性），两者统一用 Cron 表达式表达。

## 命令

```bash
sh ./bin/jinx.sh cron list                  # 列出所有定时任务
sh ./bin/jinx.sh cron detail <NAME>         # 查看指定任务的详细信息
sh ./bin/jinx.sh cron reload <NAME>         # 重新加载指定任务
```

## 创建任务

由 Agent 通过文件编辑直接创建，步骤如下：

1. 调用 `session` 工具获取当前 CHAT 会话 ID，作为 `sessionId` 字段值（任务触发后的执行结果将回写到该会话）；
   **若获取不到会话 ID（返回为空），必须终止创建并告知用户失败原因，不得写入配置文件**；
2. 使用文件编辑工具写入配置文件 `{jinx.data}/cron/{name}.cron.json`，格式见下节；
3. 执行 `sh ./bin/jinx.sh cron reload <NAME>` 立即生效（或等待约 10 秒由系统自动检测生效）。

## 配置文件

路径：`{jinx.data}/cron/{name}.cron.json`

文件名须与 JSON 中 `name` 字段严格一致。手动修改配置文件后由系统自动检测生效（约 10 秒内），也可执行 `cron reload` 立即生效。

- **删除任务**：删除对应的配置文件，系统自动检测移除；如需改名，等同删除旧配置 + 创建新配置。
- **暂停/恢复任务**：修改配置文件中 `enabled` 字段（`false` 为暂停，`true` 为恢复），由系统自动检测生效。

```json
{
  "name": "health-check",
  "cron": "0 */30 * * * ?",
  "prompt": "检查系统健康状态，如有异常生成报告",
  "enabled": true,
  "mode": "delay",
  "sessionId": "S4650279831"
}
```

| 字段 | 说明 |
|---|---|
| `name` | 任务名（英文，小写字母、数字和连字符），须与文件名一致 |
| `cron` | Cron 表达式（6 位：秒 分 时 日 月 周） |
| `prompt` | 触发时发送给 Agent 执行的指令 |
| `enabled` | 启停控制，`false` 表示暂停 |
| `mode` | 调度模式（可选，缺省 `delay`），见下节 |
| `sessionId` | CHAT 会话 ID（**必填**）：任务触发时在该会话执行并回写结果。创建前必须通过 `session` 工具获取；缺失时配置解析失败，任务不会被加载 |

## 调度模式（mode）

| 模式 | 语义 | 重叠行为 |
|---|---|---|
| `delay` | 固定延迟（默认）：上次执行**完成后**，再调度完成时刻之后的下一个 cron 触发点；错过的一次性触发点不补跑 | 天然串行，不重叠 |
| `fixed` | 固定频率：严格按 cron 时刻触发，不等待上次执行完成 | 上次未完成时允许并行执行 |

选择建议：短促任务且必须准点用 `fixed`；执行时间较长、同一任务并发会互相干扰的用 `delay`。

一次性任务（如指定具体日期的表达式）触发后无后续触发点时永久过期，不再调度。

## Cron 表达式示例

| 表达式 | 含义 |
|---|---|
| `0 */30 * * * ?` | 每 30 分钟执行一次 |
| `0 30 10 * * ?` | 每天 10:30 执行 |
| `0 0 9 ? * MON` | 每周一 9:00 执行 |
| `0 0 10 1 9 ?` | 9 月 1 日 10:00 执行（定时执行） |

## 执行记录

任务在 `sessionId` 指定的会话中执行（即哪个会话发起的任务，结果回写到哪个会话），执行历史可通过该会话查询。
