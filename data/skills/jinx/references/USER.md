# 用户档案管理

用户档案（USER）记录用户的稳定画像信息（"你是谁"），内容常驻携带于每次会话。

## 与 MEMORY 的边界

- **USER**："你是谁" —— 称呼、职业、年龄、家庭、偏好、习惯等长期稳定的个人信息。
- **MEMORY**："我们之间发生过什么" —— 对话内容、事件、一次性请求。

当用户主动告知个人信息或要求"记住我…"时，先判断是否符合 USER 的记录范围，不符合则不要写入。

## 命令

```bash
sh ./bin/jinx.sh user                       # 查看当前用户档案内容
sh ./bin/jinx.sh user reload                # 从文件重新加载用户档案
```

## 配置文件

路径：`{jinx.data}/USER.md`

写入方式：直接对该文件进行文件操作（编辑后归并去重，保持内容精炼）。文件变更会在 10 秒内自动探测生效，`user reload` 可立即生效。
